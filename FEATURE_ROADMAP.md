# OmniUI Universe &bull; Master Feature Roadmap (150+ Ideas)

This document tracks the phased implementation of all 150+ features envisioned for the OmniUI Universe platform.

## Phase 1: Developer Experience (DX) & Tooling
1. ✅ **Direct "Copy to Clipboard" for every component**: One-click code copying for all 1,700+ components.
2. ⏳ **Live Code Sandbox Integration**: Embed CodeSandbox/StackBlitz buttons.
3. ⏳ **Component "Playground" for everything**: Isolated iframe loader for every library.
4. ⏳ **VS Code Extension**: Search catalog directly in editor.
5. ⏳ **CLI Scaffolder**: `npx create-omniui-component` tool.
6. ✅ **TypeScript Type Generator**: Auto-generate TS interfaces (`component-types.json`).
7. ⏳ **Theme Config Generator**: Tailwind/CSS variable generator based on user colors.
8. 🔄 **Automated Dependency Checker**: Detect required peer dependencies.
9. ⏳ **Bundle Size Auditor**: Display bundle size impact.
10. ⏳ **A11y Scoreboard**: WCAG compliance checker using axe-core.
11. ⏳ **Browser Compatibility Table**: Auto-generate "Can I Use" chart.
12. ⏳ **Version Tracking**: Automated npm version badges.
13. ⏳ **Migration Helper**: Migration scripts between frameworks.
14. ✅ **Custom Component Registry**: Community submission form with auto-prioritization.
15. 🔄 **Local Storage "Saved Items"**: Star/favorite components list.
